# 만든 방식

이 사이트의 글은 AI 에이전트와 함께 만듭니다. 어디까지가 제 작업이고 어디부터가 에이전트의 작업인지 밝혀 둡니다.

## 과정

1. **학습**: 실제 프로젝트 코드를 보면서 에이전트에게 설명을 듣고 퀴즈를 풉니다. 문제, 제 답, 정오, 제가 되물은 질문을 세션 기록으로 남깁니다.
2. **초안**: 에이전트가 세션 기록을 재료로 챕터 초안을 씁니다. 제가 틀린 문제와 헷갈린 지점을 중심에 둡니다.
3. **검증**: 초안을 쓰지 않은 다른 에이전트가 예제 코드를 실행하고, 문장을 공식 문서와 대조합니다. 예제는 배포할 때마다 자동으로 다시 실행됩니다.
4. **검토**: 제가 직접 읽고, 문서 없이 설명할 수 없는 단락은 지웁니다.
5. **발행**: 검토를 마친 챕터만 공개됩니다.

## 읽을 때 참고할 점

- 저는 TypeScript와 프론트엔드가 본업이고, 다른 언어는 배우는 중입니다. 틀린 내용이 있을 수 있습니다.
- 예제는 특정 회사나 프로젝트의 코드가 아니라 설명용으로 새로 만든 것입니다.
- 오류를 발견하면 [GitHub 이슈](https://github.com/GrangbelrLurain/develog/issues)로 알려주세요.
