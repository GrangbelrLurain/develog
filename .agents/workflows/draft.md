---
description: 세션 기록을 재료로 챕터 초안과 실행 가능한 예제를 만든다
---

입력: 세션 기록 파일 경로 (예: `sessions/java/01-record.md`).

1. `STYLE.md`와 `AGENTS.md`를 읽는다.
2. 세션 기록에서 틀린 문제, 되물은 질문, 맞힌 문제를 나눈다.
3. `docs/<언어>/NN-<주제>.md`를 쓴다. 틀린 문제와 되물은 질문이 "내가 틀린 것" 절의 내용이 된다. 기록에 없는 주제는 추가하지 않는다.
4. 본문에서 주장하는 동작마다 `examples/<언어>/`에 실행 가능한 확인 코드를 만든다. 실제 프로젝트 코드는 중립적인 도메인으로 바꾼다.
5. 예제를 실행해 통과하는지 확인한다.
6. 머리말은 `status: draft`, `session:`에는 세션 기록 파일 이름을 적는다.
